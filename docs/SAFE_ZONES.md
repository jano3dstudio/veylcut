# Text exclusion areas

Preset margins are conservative, editable production guides (percent of output frame), not official certified masks. Each project saves its four margins. The text layout fits inside the remaining rectangle. Guide shading never enters a rendered export. An optional reference PNG is for preview only, and is not an automatically interpreted exclusion mask.

TikTok's official documentation states that safe areas vary with dimensions, caption length and additional formats: https://ads.tiktok.com/help/article/tiktok-auction-in-feed-ads . Accessed 2026-09-18.
Meta explains keeping key messages in the safe zone: https://www.facebook.com/business/ads/facebook-instagram-reels-ads . Accessed 2026-09-18.

Validate your specific placement in the destination app. All initial named presets are labeled as adjustable guides. Text within user-supplied intro/outro video assets cannot be relocated automatically.
